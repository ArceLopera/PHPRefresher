## Template Notes for Contributors

This template provides a consistent structure for all documentation pages in the PHPRefresher project. 

**How to use this template:**

1. Copy this file and rename it to match your topic (e.g., `phpNewFeature.md`)
2. Fill in all bracketed sections `[like this]`
3. Include at least one basic and one advanced example
4. Keep descriptions clear and concise
5. Always specify PHP version requirements
6. Test your changes: `mkdocs build --clean`

**When sections may vary:**

- **API Reference Pages:** May combine Overview + When to Use or show function signatures first
- **Concept Pages:** May need more detailed explanation than code examples
- **Moodle Pages:** Should reference Moodle documentation and conventions
- **Complex Topics:** May have additional subsections as needed

**Style Guidelines:**

- Use PHP 8.x syntax in examples when possible
- Show output as comments: `// Output: ...`
- Use meaningful variable names
- Add comments explaining "why", not just "what"
- Mark deprecated functions clearly
- Always link to official documentation
